# 界面与文字演出

2026-09-13 用户体验更新：字幕设置提供“原有演出动画 / 打字机·流式渐显 / 直接显示全文”，流式速度可调，点击可立即显示完整当前拍。普通换景放慢为 1.0–1.9 秒，入梦/出梦改为 2.1 秒整页中央水波遮罩；支持跳过与减少动态效果。新增书架、入梦书导入/导出和可收起的制作任务面板。出处与作者在封面、介绍、阅读和梦醒处可见。

## 画面与布局

舞台从后到前：场景图 → 有限背景调色 → 晕影与星点装饰层（律动层）→ 官方角色（仅梦外）→ 纸卡与按钮 → 设置/回顾弹层。UI 和刘看山不受背景调色影响，也不参与律动。装饰层随开场 BGM 鼓点做心跳式脉冲，幅度与降级规则见 [律动与心跳](RHYTHM_AND_PULSE.md)；正文、姓名牌与选项在任何拍上都不缩放、不位移。

桌面正文卡置于舞台下部，正文建议最大宽度 760px，整张阅读卡不超过约 960px。手机优先顶部场景 + 下方纸卡，允许长正文与选项滚动，不把对白高度固定死。操作区考虑安全边距；正文至少 18px、行高约 1.75，可调至 24px。360px 宽度和 200% 页面缩放仍可选择。

纸卡使用奶油白近不透明底与深蓝灰文字，圆角约 16–20px，细边框、轻阴影。书签与少量星点营造轻小说感；正文区不持续飘粒子，不依赖书法、发光字或毛玻璃。

## 页面与状态

| 页面/状态 | 必要内容与行为 |
|---|---|
| 选梦 | 名称、作者、题材、节选/AI 改编说明、预计时长、可玩状态；首版可只有一张主故事卡 |
| 故事详情 | 简介、题材提示、来源、改编说明；“开始入梦”与“继续上次”区分 |
| 正在载入 | 真实资源进度或文字状态；能取消；已有包不显示“AI 正在织梦” |
| 阅读 | 姓名牌、正文、继续提示；回顾、声音、设置、保存退出入口 |
| 选择 | 两个行动选项；无自动选择、无倒计时；读完当前节点后才出现 |
| 梦醒 | 终幕名、局部结果、已发生回响、梦签保存状态；重玩/梦册/原文独立入口 |
| 梦册 | 已解锁梦签与到过的分歧点；不透露未解锁终幕标题 |
| 错误 | 说明哪项失败、已保存状态与可执行操作，不只显示角色隐喻 |

正常梦内不显示刘看山。来源性质使用小标签与可展开说明；`adapted` 显示“基于节选改编”，比赛来源中的 `original` 显示“AI 衍生·梦的变体”。原创机制示例显示“原创示例”，避免无中生有地指认原作。

## 推进规则

1. 当前拍正在逐字显示时，点击正文、空格或继续按钮只使本拍完整显示。
2. 本拍已完整显示后，下一次操作才推进。末拍遇 choices 只展示选项，不能代选；遇 next 则由继续操作进入下一节点。
3. 选项点击立即锁定该次选择，结算并进入下一节点；加载或存储回调不可重结算。
4. 聚焦按钮时回车/空格只触发该按钮；弹层、输入控件或文本选择期间关闭舞台全局推进快捷键。长按键的 repeat 事件不连跳。
5. 结局末拍后显示“查看梦签”；点击进入梦醒页。原文外链只由“去知乎读原文”按钮触发。

首次提供可关闭的短提示“点一下显示完整文字，再点一下继续”，不放进角色台词。自动阅读与已读快进属于 P1：首版保留文字速度、回顾和检查点重玩即可；以后自动模式遇选择、未读内容、错误、切出页面时暂停。

## 首版四种文字表现

| anim | 中文名称 | 行为 | 默认预算 |
|---|---|---|---|
| `fade` | 轻显 | 整句淡入，无位移 | 180–250ms |
| `typewriter` | 逐字 | 稳定速度，可立即跳完 | 默认约 35 字/秒，可调速度或瞬显 |
| `emphasis` | 落定 | 整句显示后短暂字重/底色强调，无震动 | 200–300ms，每梦包建议不超过 3 拍 |
| `none` | 静置 | 立即完整显示 | 0ms |

默认 fade，高潮也可完全静置。`none` 只控制文字，不隐式关闭音乐或音效；真正静默须给 `musicCue: {action: silence}` 并省略 sfx。未写音效不自动补逐字声。

```json
{
  "id": "last-page",
  "kind": "narration",
  "speaker": "narrator",
  "text": "你把书签放下，窗外的光恰好落在那一页。",
  "anim": "none",
  "musicCue": {"action": "silence"},
  "sceneShift": "BG_END"
}
```

重要台词不强制同时绑定动画、音效、音乐。原 14 种效果是历史候选。原"首版不做文字扭曲"的一刀切结论已按用户最新要求修订，见下文"文字演出效果库"；闪屏、正文区持续动画、长时间模糊仍然不做。场景交叉淡入 300–500ms，可跳过；调度器取消旧动画后再进入新拍。

## 文字演出效果库

用户明确说明"文字碎裂只是举例，不代表唯一效果"。因此本节从"两种特写"扩为**效果库**：按场景选效果，而不是固定一种动画。参考方向是 CodePen / Codrops 一类的现代文字表现，但每一条都必须落在下面的预算与无障碍约束内才能进库。

这里再次**修订**上一版结论。原文写"首版不做闪屏、文字扭曲、持续颤动和长时间模糊"，其中"文字扭曲"已在上一轮有条件放开；本轮进一步放开**极低幅度的持续微动**（漂浮、呼吸），但限制到非正文文本。修订后的禁项清单如下，未列入的一律不做：

- 仍然禁止：闪屏、频闪、大面积快速明暗切换。
- 仍然禁止：**正文区**的任何持续动画——阅读中的正文、对白、选项必须绝对静止。
- 仍然禁止：长时间模糊、正文区持续飘粒子。
- 仍然禁止：让文字在特效期间无法读、无法选中、无法被朗读。
- 仍然禁止：幅度大到影响可读性的形变、抖动、颤动。
- 有条件允许：**有明确起止的一次性入场/退场演出**（A 类、B 类）。
- 有条件允许：**幅度极小、仅用于非正文文本的持续微动**（C 类），见该类的专门限制。

### 三类效果与分层

| 层 | 名称 | 何时结束 | 可用范围 |
|---|---|---|---|
| 基础层 | `fade` / `typewriter` / `emphasis` / `none` | 立即或短预算内 | 任何拍，默认选择 |
| A 类 | 入场演出 | 预算内结束并回到静态 | 拍的开始，配额受限 |
| B 类 | 退场演出 | 预算内结束，随后该拍消失或转场 | 拍的结束、终幕、转场，配额受限 |
| C 类 | 持续微动 | 不结束（循环） | **仅**标题、终幕名、梦签、装饰性短文本 |

基础层永远是多数拍的选择。A/B 类是稀缺资源；C 类不是"演出"而是"氛围"，两者配额分开计算。

### A 类：入场演出

| effect | 中文名 | 行为 | 时长预算 | 适合的场景 |
|---|---|---|---|---|
| `emerge` | 浮现 | 由透明与极轻下位移（≤6px）浮升到位，无模糊、无缩放 | 400–700ms | 最通用的入场，安静叙述、回忆起头 |
| `focusIn` | 模糊聚焦 | 由轻模糊到清晰，伴极轻缩放（1.02→1.00） | 500–800ms | 梦境转清醒、视线聚焦、场景刚切换 |
| `inkBloom` | 墨迹扩散 | 每字以极轻的边缘渗染感由中心显出，字间有 20–40ms 的顺序错峰 | 600–1000ms | 书写感、信件、题字、旧文献 |
| `particleGather` | 光粒聚合 | 少量光点向字形位置汇聚并淡出，字随之显出 | 700–1100ms | 奇幻显现、梦的开端、超现实时刻 |
| `liquid` | 液态 | 如从水面浮出：轻垂直位移 + 沿基线低频波动 + 由模糊到清晰，波幅衰减到 0 | 600–900ms | 入梦、水／镜面意象 |
| `dreamRipple` | 梦境波纹 | 一道极轻的波纹自左向右扫过并带出文字，波峰位移 ≤3px | 700–1000ms | 梦内叙述的开场，与入梦音效同期 |
| `pageTurn` | 页面翻动式 | 文字随一次极轻的纸面翻起感显出（透视 ≤4°，无投影动画） | 500–800ms | 章节起头、分幕、与翻页音效同期 |
| `scramble` | 字符错位重组 | 字先以错位／占位状态出现，短时间内归位为正确文本 | 600–900ms | 记忆错乱、身份揭示、不可靠叙述 |

`scramble` 有一条额外硬规则：**过渡期间不得显示任何可读成其他含义的字符串**。用同一文本的字符打乱或用中性占位符（如"□"）过渡，不引入未经审读的文字。屏幕阅读器只读最终文本，过程完全不进无障碍树。

### B 类：退场演出

| effect | 中文名 | 行为 | 时长预算 | 适合的场景 |
|---|---|---|---|---|
| `shatter` | 碎裂 | 文字按字裂成若干片，各片轻微位移、旋转 ≤8°、淡出；不产生碎屑粒子 | 500–800ms | 断裂性结局、决裂、物件损毁 |
| `dissolve` | 溶解 | 字逐渐失去边缘并淡出，无位移、无旋转，比碎裂柔和 | 600–1000ms | 遗忘、消散、温和的告别 |
| `particleScatter` | 光粒散逸 | 字化为少量光点向外飘散并淡出，是 `particleGather` 的反向 | 700–1100ms | 梦醒瞬间、超现实收尾 |
| `inkFade` | 墨迹褪去 | 如墨在纸上被水化开后变淡，边缘先软后消 | 600–1000ms | 书写感的收尾、信件读完 |

拆字类效果（`shatter`、`scramble`、`inkBloom`）CJK 按单字、拉丁按词切分，不做笔画级切割——那依赖字体内部结构，跨字体不可靠。

### C 类：持续微动（严格限制）

这类不结束，因此限制最紧。**只允许**用于：故事标题、章节／分幕名、终幕名、梦签上的短句、梦斋里的装饰性短文本。**绝对禁止**用于正文、对白、选项、按钮、姓名牌、界面标签、错误信息、来源标签、保存状态。

| effect | 中文名 | 行为 | 幅度上限 | 周期 |
|---|---|---|---|---|
| `float` | 轻微漂浮 | 整体极缓上下浮动，无旋转、无缩放 | translateY ≤2px | 3.5–6s，缓入缓出 |
| `breathe` | 呼吸 | 极轻的透明度起伏，不改变字号与位置 | opacity 0.88–1.00 | 3.5–6s |

共同约束：

- 周期下限 3.5 秒，即频率 ≤0.29 Hz，远低于律动的 2.0 Hz 上限，不构成闪烁风险。
- 一个页面同时运行的 C 类元素 ≤2 个；不对同一元素叠加 `float` 与 `breathe`。
- 不与律动心跳同相，也不试图对齐节拍——它是独立的慢氛围，跟拍会显得机械。
- 阅读页除标题外不出现 C 类。**读者眼睛落在正文时，视野内不得有任何持续运动**，这是比"效果丰富"更高优先级的要求。
- `prefers-reduced-motion` 或"关闭动画"下，C 类完全停止并停在中间态（`float` 停在 0 位移，`breathe` 停在 opacity 1.0）。

### 场景到效果的建议映射

按场景选，不必每个场景都用满。同一个梦包内反复用同一个 A 类效果，比每拍换一种更耐读。

| 场景 | 建议 | 说明 |
|---|---|---|
| 普通正文拍 | 基础层 `fade` / `typewriter` | 绝大多数拍都在这里 |
| 入梦第一拍 | `liquid` 或 `dreamRipple` | 与 `SFX_DREAM_IN` 同期 |
| 章节／分幕标题 | `pageTurn` + 标题可挂 `float` | 与翻页音效同期 |
| 梦内叙述开场 | `dreamRipple` 或 `focusIn` | 提示"这里是梦"，但含义仍由文字写出 |
| 回忆片段起头 | `inkBloom` 或 `emerge` | 书写感／旧纸感 |
| 奇幻显现 | `particleGather` | 每包不宜超过 1 次 |
| 关键转折短旁白 | `emphasis`（基础层）优先，必要时 `focusIn` | 转折靠文字本身，不靠特效 |
| 记忆错乱／身份揭示 | `scramble` | 注意上文的字符安全规则 |
| 温和结局末拍 | `dissolve` 或 `inkFade` | |
| 断裂性结局末拍 | `shatter` | |
| 梦醒瞬间 | `particleScatter` | 与 `SFX_DREAM_OUT` 同期 |
| 终幕名、梦签短句 | `breathe` 或 `float` | C 类唯一的常规位置 |
| 选项、按钮、错误、来源、保存状态 | 一律静态 | 无例外 |

|---|---|---|---|
| 结局末拍旁白 | 允许 | 允许 | 不允许 |
| 入梦第一拍 | 允许 | — | 不允许 |
| 章节／分幕标题 | 允许 | 允许 | 允许 |
| 关键转折短旁白（≤24 字） | 允许 | 不允许 | 不允许 |
| 普通正文拍 | 不允许 | 不允许 | 不允许 |
| 对白（有姓名牌的拍） | 不允许 | 不允许 | 不允许 |
| 选项文字 | 不允许 | 不允许 | 不允许 |
| 终幕名、梦签短句 | 允许 | — | 允许 |
| 按钮、姓名牌、界面标签、错误、来源、保存状态 | 不允许 | 不允许 | 不允许 |

### 每包配额

- A 类 + B 类合计 ≤6 拍（上一版是 ≤3，因效果库扩大而放宽），其中**拆字类**（`shatter`、`scramble`、`inkBloom`）合计 ≤3 拍。
- 同一路线上任意连续 4 拍内不得出现 2 次 A/B 类。
- 单个梦包内 A 类效果种类 ≤4 种，B 类 ≤2 种。效果种类过多会让演出显得杂乱，这条限制的是**多样性滥用**而不是总量。
- C 类不计入上述配额，但单页同时运行 ≤2 个。
- 单拍只能有一种表现：A/B 类与 `typewriter`、`emphasis` **互斥**，不叠加。`anim` 与 `effect` 同时给出时发布器报错，不自行取舍。
- 超配额的梦包不能通过发布校验；由校验器判定，不靠写作自觉。

### 契约字段

效果作为拍上的独立可选字段 `effect`，与 `anim` 平级但互斥：

```json
{
  "id": "ending-break",
  "kind": "narration",
  "speaker": "narrator",
  "text": "那一页在你手里散了。",
  "effect": {"type": "shatter", "durationMs": 700, "intensity": "normal"},
  "sfx": "SFX_PAGE_DEEP",
  "sceneShift": "BG_END"
}
```

- `type` 取值限定为上表三类中的具体名称，不接受任意字符串；未知值按 `fade` 降级并记一条校验警告。
- `durationMs` 必须落在该 type 的预算区间内，超出则夹到边界并警告。C 类不接受 `durationMs`，其周期由客户端实现决定。
- `intensity` 取 `soft` | `normal`，仅缩放幅度，不改时长；不提供 `strong`。
- 不接受自定义 CSS、着色器代码、外部 URL 或任意参数对象。效果实现在客户端，梦包只能选档，这与"`file` 禁止远端代码"是同一条安全边界。
- 客户端不认识某个 `type` 时降级为 `fade` 并继续，不阻断阅读。**新增效果必须同步 schema 白名单、校验器与本表**，三处不一致以本表为准。

### 实现约束

- 拆字用 DOM 时，单拍拆分节点数 ≤48。超过则不拆字、退化为整句效果（`emerge` 或整句淡出），不允许生成上百个节点。
- 只用 `transform`（translate/rotate/scale）与 `opacity` 做动画。`filter: blur` 仅允许用于 `focusIn`、`liquid`、`dissolve`、`inkFade`、`inkBloom`，半径 ≤3px 且持续 ≤400ms。不做 `text-shadow` 逐帧动画。
- `particleGather` / `particleScatter` 的光点数单拍 ≤24，用单一图层绘制（CSS 或一个 canvas），不为每个光点建 DOM 节点。它们是唯一允许出现粒子的效果，且**只在这两个效果的时长内存在**——正文区仍然禁止持续飘粒子。
- 效果层是**装饰副本**：真实文字节点始终存在于 DOM 且可选中；装饰层 `aria-hidden`，动画结束后移除。绝不用效果层替换真实文字。
- 效果不得延迟输入：动画进行中点击/空格**立即结束效果并完整显示该拍**，与基础层"点一下显示完整文字"一致；不需要等效果播完才能推进。
- 效果不改变拍的推进语义：末拍遇 choices 仍是读完才出选项，效果不构成"未读完"。
- 字体未加载完成时不启动效果，先静态显示，避免字形替换造成的重排跳动。
- 首帧前预计算所有片的目标值，动画期间不再读取布局属性，避免逐帧重排。
- 所有 A/B 类共用一个调度器：进入新拍时取消上一拍未完成的效果，不允许两个效果同时改同一段文字。

### 降级与无障碍

- `prefers-reduced-motion: reduce` 或"关闭动画"：A/B 类**替换为立即完整显示**（等价 `none`），C 类停在中间态。不做削弱版、不保留模糊、不保留粒子。
- 屏幕阅读器读取完整语句一次；装饰层不进无障碍树，不逐字通知。拍变化只播报一次。`scramble` 的过渡文本永不进无障碍树。
- 效果不携带任何剧情信息：关掉之后文本内容与情节完全一致。碎裂不代表"这句是假的"，波纹不代表"这里是梦"——这类含义必须由文字本身写出来。
- 性能保护与律动共用一套档位（见 [律动与心跳](RHYTHM_AND_PULSE.md)）：低帧率档位下 A/B 类自动降级为 `fade`，C 类停止。粒子类效果在最低档位直接跳过。
- 效果期间不改变对比度与字号；结束态必须与静态排版逐像素一致，不留下 0.5px 的位移残留。
- C 类的持续运动必须可单独关闭，不要求玩家为了关掉标题漂浮而关掉全部动画。

### 验收

1. 每种效果在桌面与 360px 宽度手机上各看一遍：起止清楚，A/B 类结束后完全静止。
2. 动画中途点击：立即完整显示，不卡、不重播、不吞掉这次操作。
3. 开"关闭动画"：A/B 类变立即显示，C 类停住，页面无残留动画。
4. 屏幕阅读器：整句读一次，无逐字噪声，无重复播报；`scramble` 不读出过渡字符。
5. 阅读正文时截图连拍对比：视野内无任何持续运动，正文逐像素不位移。
6. 键盘全程操作一遍带效果的路线：焦点顺序不被装饰层打乱。
7. 中低端机连续经过 6 个效果拍：无掉帧堆积，或按降级规则自动退档。
8. 故意写一个超配额（7 次 A/B 类，或 4 次拆字类）的测试梦包：发布校验必须失败。
9. `scramble` 逐帧检查：过渡期间不出现可读成其他含义的字符串。

## 无障碍与故障

- 尊重 `prefers-reduced-motion`，提供“关闭动画”；开启后四种表现均立即显示，转场直接切换，角色用静帧。音量独立设置。
- 持续装饰动画可暂停；触控区域至少 44×44 CSS px，焦点轮廓清楚。键盘可访问全部操作，弹层关闭后焦点回原入口。
- 屏幕阅读器读取完整语句，不逐字通知；拍变化只播报一次。视觉逐字层可标为装饰，避免双重朗读。
- 作者与角色不能只靠颜色区分；错误、来源和保存状态有真实文字。对比度按 [视觉风格](VISUAL_STYLE.md) 验收。
- 存档失败显示“进度尚未保存”，可继续、重试或导出；不能显示虚假“书签已收好”。断网只对缺失资源报错，已缓存故事可继续。
