# 视觉风格：清透的二次元梦境书屋

## 统一美术方向

关键词：**二次元背景美术、清爽线条、柔和赛璐璐明暗、奶油白、雾蓝、晨光、纸页、安静奇幻**。梦斋是现代奇幻书屋；梦内沿用原作的建筑、时代和物件。原有“宋元水墨”“统一古风”“换调色盘就是换世界观”不再执行。

视觉重点依次为正文与选择、场景情绪、官方角色。二次元不等于高饱和、满屏光效或少女立绘；首版通过背景、对白卡、姓名标签和梦签构成明确风格。

## 官方刘看山如何融入

已检查 3 个 JPG 和 6 个 GIF 的首帧。素材是白色、黑鼻与黑色手脚、带柔和体积感的卡通角色，非平涂人类立绘。保留其原貌，在画面里作为梦斋的官方吉祥物呈现，允许背景与角色采用不同表现技法。

- 梦斋用柔和大色块、少量细节与浅色环境，避免极密线稿、重油画、写实镜头感。
- 角色层在背景调色层之上；不改变角色颜色、比例与面部，不加服装、不重绘、不用 AI 复刻。
- 可在角色下方独立放一个柔和椭圆地面阴影作为界面元素，不烘焙进原始素材。
- 角色尺寸桌面约 128–176 CSS px、手机 88–112 CSS px；不超过原 320px 画布的合理显示范围，先保证对白与按钮不被遮挡。
- 正常梦内阅读不常驻，免得卡通动作打断严肃情节。仅首页、入梦过渡、梦醒与真实制作状态使用。
- 三份 JPG 分别是三视参考板、白底姿态图、绿底姿态图，均无透明通道。不能把整张绿底 JPG 当作透明贴图直接使用。

## 色彩与字体

| 角色 | 默认值 | 使用方式 |
|---|---|---|
| 页面底色 | `#F5F7FC` | 清透浅雾白 |
| 纸卡底色 | `#FFFDF7` | 对白、梦签、故事卡 |
| 正文 | `#24324A` | 常规正文必须清楚可读 |
| 次要文字 | `#52627A` | 来源、元信息，仍需检查对比度 |
| 主操作 | `#365EB5` | 按钮填色，白字；这是项目配色，不声称官方品牌色值 |
| 梦境点缀 | `#C9BEF3` / `#F5D9A7` | 雾紫与灯光金，避免直接作小字号文字 |

UI 与正文默认 Noto Sans SC；故事标题可用 Noto Serif SC。书法字体不再作为主标题默认。先用本地系统字体立即显示，字体子集异步载入；字体版本与 OFL 许可随资源记录。

普通正文对比度目标至少 4.5:1；焦点框和重要组件边界至少 3:1。背景图上叠加足够实的纸卡，不依赖“低对比背景”碰运气。

## 场景体系

保留英文场景 ID 便于后续复用；ID 是语义槽，不表示任何题材都能直接共用同一张图。

| ID | 首版状态 | 场景语义与制作要求 |
|---|---|---|
| `BG_GATE` | P0，先生成 | 云光书屋、书架、阅读角，右下留守梦位 |
| `BG_ROOM_D` | P0 | 无鲜明职业标识的现代小阅读室，白日漫射光 |
| `BG_STREET` | P0 | 安静现代街道、转角与远处路灯，不画可读招牌 |
| `BG_END` | P0 | 梦斋窗边的空白书页与微光，用于梦醒梦签 |
| `BG_ROOM_N` | P1，夜景需要时 | 对应室内的夜间版本；实物灯源须成立 |
| `BG_ROAD` | P1 | 现代步行小路或站台；选题后选一种，不混拼 |
| `BG_WILD` | P1 | 自然空地、草坡与天空 |
| `BG_DEEP` | P1 | 同一时代的封闭通道或紧张空间，避免血腥 |
| `BG_PALE` | P1 | 回忆中的阅读室，柔化细节，不烘焙模糊正文 |

P0 四张服务首个精选故事的前提是该故事场景确实匹配。具体选题若不匹配，先改清单再生成，不能用室内图冒充车厢或朝堂。古代、幻想题材需要对应建筑/道具版本，例如 `bg-room-d-historical.webp`；由资源目录映射到同一语义槽。

## 构图与适配

- 背景不含人物、官方角色、可读文字、印章、按钮、水印；角色、界面文字由应用独立叠加。
- 横版目标 2560×1440；工具只能输出更小时接受至少 1920×1080，不为了凑数先放大。母版另存，发布再压缩。
- 下方 35% 保持细节安静；主要空间信息保留在中央 40% 宽度，测试桌面与手机居中裁切。
- 手机纵向界面可以采用顶部场景图 + 下方纸卡，不必强行全屏裁横图；需要时补 9:16 竖版，撤销“禁止竖图”。
- 保留少量环境透视与焦点，不全图低对比；由 UI 底板保证文字可读。夜景可暗，但主阅读卡保持稳定。
- 日夜不能总靠全图变蓝；必要时生成有正确窗外与灯源的独立夜图。雨、雾可由轻图层补充，减少动态效果时全部关闭。

## 切换与调色

默认场景交叉淡入 300–500ms，可点击跳过。首版不做墨晕与大面积扭曲；减少动态效果时直接切换。留在同一地点的连续节点保持背景，不为“画面变化”无故换场。

首版预设 `calm`、`warm`、`mystery` 三种有限调色方案，调色不覆盖 UI 与刘看山。AI 只能选择预设，不能输出任意 CSS 或颜色脚本。历史和新增题材先审场景，再谈复用。
