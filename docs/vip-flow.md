# 产品闭环设计：3000 字试读 → AI 扩写游戏 → VIP 导流

状态：设计文档，未实现。所有实测数据见文末。

## 一、VIP 机制确认（实测）

`https://www.zhihu.com/fiore/h5/vip-web` 是知乎**盐选故事**的会员页，按"推荐榜 / 热搜榜 / 热度榜 / 口碑榜 / 长篇榜"组织，题材标签有言情、脑洞、现实情感、甜宠、爽文、治愈、虐恋、悬疑惊悚等。

关键结论：**比赛接口正文恰好 3000 字不是 bug，是免费试读边界。** 盐选故事非会员只能读开头约 3000 字，会员可读全文——比赛接口返回的 `content` 就是这个免费试读段的原文。两个数字完全吻合（实测 20 篇 story 里 19 篇恰好 3000 字，10 篇 knowledge 里 9 篇恰好 3000 字）。

这反过来证明：**比赛接口给的内容是合法授权的试读段**，拿它做游戏素材没有任何越界。

## 二、产品闭环

```
玩家导入知乎故事
   │
   ▼
比赛接口取试读段（3000字，授权内容）
   │
   ▼
AI 提取主线骨架 + 人物性格 + 语气特征
   │
   ├─────────────────┐
   ▼                 ▼
主线：忠实改编      支线：AI 扩写
（3000字内完整覆盖）（梦的变体，标注衍生）
   │
   ▼
玩家推进到试读边界
   │
   ▼
世界观内化的提示 → 导流知乎站内继续阅读（VIP）
```

**这个闭环里各方的所得：**

| 角色 | 得到什么 |
|---|---|
| 玩家 | 免费玩到试读段的游戏化 + AI 衍生支线；想读原文后续去知乎 |
| 知乎 | 盐选内容的又一个消费入口；试读段的游戏化本身是种草 |
| 项目 | 合法、可持续的内容供给，不用解决"全文版权"这个死结 |

## 三、一个必须先想通的分寸问题

**AI 扩写不能变成"VIP 的免费平替"。** 如果玩家不买会员也能玩到"后续剧情"，那导流就成了空话，而且对知乎是负价值（用 AI 衍生内容稀释了付费内容的稀缺性）。

所以边界要这样划：

- **试读段内（0–3000 字）**：主线忠实改编 + 多分支选择。玩家在这里免费获得完整体验。
- **AI 扩写**：只做**支线和"梦的变体"**——比如"如果当时没推开那扇门"的平行展开，明确标注是游戏衍生物，不是原文后续。
- **原文后续主线**：游戏**不写**。到试读边界就停，把"想看真正后续"的意愿导向知乎。

这样 AI 扩写和 VIP 内容是**互补**而不是竞争：游戏负责让玩家对故事和人物上头（种草），知乎负责收割阅读欲（转化）。游戏自己不做原文的"第二作者"。

## 四、提示的设计原则：世界观内化

结合既定要求（"游戏过程中不要出现开发者式提示，要让用户自己联想到"），VIP 提示**不能是弹窗广告**，必须用游戏的语言说出来。

**禁止的写法：**

> ❌「开通知乎盐选会员，解锁完整故事！」

**推荐的写法（枕中记世界观）：**

试读边界处，剧情自然走到一个悬置点，然后：

> 梦至此处，纸页已尽。
> 后卷之梦，记于知乎书阁。
> （静置数秒后浮现一个含蓄的落款链接）

文案候选，按含蓄程度排序：

1. **「此卷至此。后梦在纸上，不在梦中。」** —— 最含蓄，链接做成"纸上"二字的可点击点染。
2. **「梦有未尽处。原文后卷，藏于书阁。」** —— 稍明确，"书阁"链接到知乎原文页。
3. **「黄粱未熟，前梦已记半卷。欲知后事——」** —— 用说书人断章的方式，最符合古典章回体。

**交互规则：**

- 只在试读边界出现**一次**，玩家选择"继续此梦（衍生支线）"或"醒来"都行，不重复打扰。
- 链接必须带 UTM 参数（开放平台本来就给每条内容带 `utm_source`），让知乎能看到这批流量从哪来。
- 玩家选了衍生支线就正常继续游戏，绝不再提 VIP 的事。
- 结局页可以再放一次原文链接（作为"回看此生的出处"），那是自然的、非推销的语境。

## 五、与既有模块的整合

| 模块 | 关系 |
|---|---|
| **BYO-Key（知乎）** | 玩家自己的 Key 走开放平台搜索找故事；比赛接口的 20 篇是预置内容池，不需要 Key |
| **BYO-Key（LLM）** | AI 提取与扩写消耗玩家自己配的模型；未配置时只能玩预置故事（内置枕中记包） |
| **刘看山素材** | IP 形象是"入梦的向导"——它出现在提示场景正合适：由 IP 角色说出"后卷在书阁"，比系统弹窗自然得多。素材已实测转 WebP（1.38 MiB），接入方案见素材文档 |
| **场景与配乐复用** | 盐选题材 = 言情/脑洞/悬疑/爽文，与古风资产错位，仍需定"转译框架"路线（见 art-prompts.md 复用边界一节） |
| **诚实标签体系** | 三档标注：`原典改编`（枕中记）/ `试读改编`（3000字内忠实）/ `衍生创作`（AI 扩写支线）。游戏内可见，不混用 |

## 六、合规与诚实边界

- **不替知乎承诺**：游戏文案只说"原文后卷在知乎"，不出现"开通会员仅需 XX 元"之类的价格与促销话术——定价和权益是知乎的事，我们只做指路。
- **不抓取**：即使玩家自己是 VIP，游戏也不去抓全文（技术上开放平台也不给）。VIP 解锁的是玩家在知乎站内的阅读，不是游戏的数据。
- **衍生内容明确标注**：AI 扩写的支线永远标"衍生创作"，不在任何地方冒充原文后续——这既是版权分寸，也是对玩家的诚实。
- **导流可度量**：所有指向知乎的链接带 UTM，知乎侧可自行核验这个入口的价值。这对比赛叙事是加分项：不是口号式"为知乎导流"，而是可验证的流量。
