# 二次元美术提示词：逐张制作

本文件替代旧美术提示词的制作方向。用户逐张生成，先完成 `BG_GATE` 定调；首图满意后再做下一张。2026-09-12 已接收用户生成的 BG_GATE、BG_END，目视检查两图风格一致，并归档母版、转换 WebP；实际 UI 叠加和设备验收待应用实现。人类角色立绘和剧情 CG 暂缓，刘看山直接用官方素材，不交给模型重画。

## 统一要求

清透的二次元背景美术，柔和赛璐璐明暗、整洁而不过密的线条、奶油白与雾蓝、少量浅木色和暖金色。整体温柔、可亲、有一点奇幻，但故事内保留真实空间逻辑。避免重水墨、写实照片、塑料 3D 渲染和高饱和手游大厅。

默认横版 16:9、目标 2560×1440，至少原生 1920×1080；若工具只支持其他原生尺寸，保持比例与构图，后续导出时处理，不宣称放大就增加真实细节。母版先保留 PNG，发布 WebP 在工程接入时制作。

背景不要文字、人物、角色、按钮和水印。界面会叠加在画面下方，所以底部约 35% 细节平静；主要空间线索保留在中央约 40% 宽度。手机优先顶部横图，不必把所有横图强制裁成竖屏全屏。

以下各条均是完整提示词，可单独复制。工具支持负面提示时另填统一排除项；不支持时附在主提示词末尾：

> 不要人物、动物、吉祥物、刘看山、人物剪影、可读文字、书名、数字、招牌字、Logo、水印、UI 按钮、边框；不要写实摄影、重水墨、厚涂油画、塑料 3D、过亮泛光、镜头光斑、满屏粒子、杂乱装饰、霓虹高饱和、错误透视、扭曲书架或悬空家具。

## 第 1 张：BG_GATE｜云光梦斋

用途：首页与选梦的风格锚点。文件目标 `bg-gate.png`，发布时为 `bg-gate.webp`。

> 一张用于中文互动小说游戏的二次元背景插画，横版 16:9。清透、温柔的现代奇幻书屋内部，称为“梦斋”，但画面中不要任何文字。奶油白墙面、浅木色地板和简洁的书架，书架靠画面左侧与后方，书脊全都没有可读文字。中央偏后是一扇宽而轻盈的拱形窗，窗外是雾蓝天空与柔软云层，晨光从左上方斜照进来。几本书和一盏小灯自然放在远处的阅读桌上，只有极少量安静的奇幻细节。中景层次清楚、透视自然，像动画电影中让人愿意停留的阅读空间；整洁细线、柔和赛璐璐明暗、大块轻柔颜色，不要写实照片或塑料 3D。主要空间结构集中在画面中央约 40% 宽度。底部约 35% 保持低细节，给后续叠加对白和操作卡片；右下方留一片有地面支撑的干净空位，稍后会由程序放置一个白色官方吉祥物，但这张图中绝对不要画吉祥物或任何人物。少量雾紫与灯光金作为点缀，清爽、温暖、有探索故事的好奇感。无文字、无 UI、无 Logo、无水印。目标 2560×1440。

首图验收只看三件事：像二次元书屋；白色官方角色放进去不突兀；正文纸卡盖住底部后仍认得书屋。第一次生成可出两个构图候选，选定一个后固定为参考，勿先生成全部背景。

若失败，按主要问题只改一个方向：

- 太像照片：“保留空间结构，改成清晰但稀疏的动画背景线条，减少真实材质纹理，用柔和赛璐璐分面表现体积。”
- 太花：“保留窗、书架、地面三种核心元素，删除悬浮装饰和复杂摆件，让下方更安静。”
- 白色角色融不进：“背景增加浅木色与雾蓝地面层次，避免角色背后整片纯白；不修改角色本体。”
- 构图拥挤：“镜头稍后退，减少近景家具，将主要结构移入中央，右下地面保持空出。”

## 暂缓的场景

`BG_ROOM_N`、`BG_ROAD`、`BG_WILD`、`BG_DEEP`、`BG_PALE`、`BG_WARP` 仅预留语义槽，首版不要求出图。需要某张时先确定场景、时代、时段，再以已选背景为参考追加；不能让简单调色替代灯源、建筑和道具变化。

人物立绘后续再做。要做时先固定该故事人物的年龄、服装、轮廓、发型和基本表情，生成同一母版的变体；不让每张立绘单独随机生成。

## 一张图如何交付与验收

保留原始生成文件、工具/模型、日期、使用的提示词及生成任务信息；支持随机种子的工具再记 seed，不支持的不补造。正式素材来源在 manifest 中记录，不在图片上烘焙说明文字。

依次检查原图 → 桌面纸卡叠加 → 360px 手机顶部横图 → 必要的竖版适配 → 官方角色叠加 → 压缩后的发布图。确认没有人物、乱码、透视错误、侵入阅读区的亮斑，以及官方角色白边或遮挡。生成后的观感与布局通过后才进入下一张。

手机需要独立竖版时，沿用选定横图作参考，改为 9:16：保留核心窗/道路结构在上半部，下半部留阅读空间；重新组织构图，不能只把横图左右裁空。UI 文案、按钮和梦签都在网页中排版，不随图片生成。


## 首篇《吃人心的小妖怪》的场景（2026-09-13 定）

首篇选定后，`BG_ROOM_D`（白昼阅读室）与 `BG_STREET`（傍晚街角）**不适用**：那两张是按现代题材预设的，本篇是古代山野。两个槽位转为暂缓，不删除定义，将来若有现代题材故事可直接复用。

下列五张按剧情实际需要定义。`BG_GATE`、`BG_END` 继续用于梦外（梦斋门前、梦醒梦签），不进梦内。

统一沿用上文《统一要求》：清透二次元、柔和赛璐璐明暗、奶油白与雾蓝加浅木色暖金、整洁不过密的线条；无人物、无动物、无吉祥物、无 UI、无 Logo、无水印、无可读文字；横版 16:9，目标 2560×1440；底部约 35% 留干净区域以便叠加纸卡，中央约 40% 保留主要空间关系。

**动物必须缺席**，即使剧情里有小鹿、獐子、野鸡：它们是角色，背景一旦画死就会在所有拍里静止不动。同理不画小妖怪、念念、毓娘。

每张标注"律动区域"，供心跳律动系统使用：该区域的亮度或轻微缩放随节拍脉动，其余部分保持稳定。区域必须是画面里本就会发光或透光的部位，不能是任意色块，否则脉动看起来像故障。
