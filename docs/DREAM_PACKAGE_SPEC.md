# 剧情数据契约 v1

本文说明当前运行格式。完整字段、严格校验与上限以 [schema.ts](../src/game/schema.ts) 和 [validate.ts](../src/game/validate.ts) 为准；打包容器见 [入梦书格式](DREAMBOOK_FORMAT.md)。

## 故事与来源

`story.json` 包含 `schemaVersion`（固定 1）、`packageId`、`buildId`、标题、来源、审读状态、主题、人物、资源、关系、旗标、入口节点及节点数组。ID 使用英文标识，修改故事内容或逻辑须更换构建号。

来源类型包括 `hackathon_excerpt`、`original_demo`、`original_work`、`external_excerpt`。保存原作者、原文地址、节选性质、规范化正文的 SHA-256 与使用依据；可选作者主页和发布日期。未知或待确认信息不能自动标为已审核。内容来源是作品数据，不应加入开发机器路径。

## 节点、对白与条件

| 数据 | 规则 |
| --- | --- |
| `scene` 节点 | 背景、对白数组；后继使用 `next`、`nextWhen` 或 2–3 个 `choices` |
| `ending` 节点 | 背景、对白及结局标题/摘要；无后续连接 |
| `beat` | 唯一 ID、`kind`、`speaker`、纯文本；可选条件及有限演出 |
| `narration` | `speaker=narrator` |
| `dialogue` / `thought` | speaker 引用人物；心声与旁白分开表现 |
| `choice` | 文本、目标节点、条件及 `effects` |
| `effects` | `setFlags`、资源增量、关系增量；允许空对象或数组 |

条件采用 `{all: [...], any?: [...]}`：`all` 的谓词全部成立，`any` 若存在则至少一个成立；两组不能同时为空。谓词允许检查旗标是否为指定布尔值，或资源/关系是否满足 `eq`、`gte`、`lte`。不接受 JavaScript、表达式或远程脚本。正常推进只能将旗标从 false 置为 true；回退通过历史重放恢复此前状态。

`nextWhen` 是 2–4 个 `{when, target}` 条目，在当前状态下必须恰好命中一条。没有匹配或多重匹配都拒绝推进，不使用默认结局。普通节点只选一种后继方式；中途选择另设 `choiceAfter` 拍 ID，选项 `target` 全部指向本节点，结算后从该边界后继续阅读，再按 `next` 或 `nextWhen` 离开节点。这种继续阅读不重播节点前半段，也不产生图上的循环。

有限演出包括文字动画、一次性音效、背景切换 `sceneShift` 以及 `musicCue` 配乐控制。可选 `effect` 与 `anim` 互斥，类型和时长必须符合代码白名单。立绘、章节名和场景氛围放在素材包的 `presentation` 中。

拍可用 `textSpeedScale`（0.5–1）降低渐显速度；`0.8` 对应常规速度的 80%，字间隔除以该系数。配乐 cue 只在指定拍改变曲目，跨节点未指定新 cue 时连续播放。人声单次播放保护由音频素材的 `vocal` 字段声明，详见 [入梦书格式](DREAMBOOK_FORMAT.md)。

## 容量与校验

普通梦包最多 32 节点，每节点最多 20 拍；显式 `edition=longform` 扩展到 96 节点、每节点 160 拍。人物最多 6 个、资源 2 个、关系 1 个、旗标 32 个；剧情 JSON 最大 1 MiB。长篇采用扩展演出配额，其余语义与普通包相同。

校验器检查字段、ID、资源引用、图的可达性、循环、全部路线可结束、选择是否可执行、数值范围和终幕是否可达。状态探索上限为 10,000 个组合，超限拒绝。程序校验不替代剧情审读或素材使用依据确认。

## 存档与回放

存档按 `packageId + buildId` 隔离，保存位置、剧情变量、选择历史和检查点。前后对话队列最多保留 30 条，自动档与手动档独立。自动档保存选择前最后一句；下一个选择覆盖它。

恢复时按实际选择路径重建剧情事实和演出状态，不重播一次性音效、不重复执行选择。重选分歧清除旧路线的前进记录，梦签收藏独立保留。无法与当前构建匹配的存档不静默覆盖，用户可导出备份或使用相应旧素材包。

实现见 [剧情引擎](../src/game/engine.ts)、[重放校验](../src/game/replay.ts) 与 [存储模块](../src/game/storage.ts)。
