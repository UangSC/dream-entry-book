# 《一枕千生》验收记录

日期：2026-09-12。剧情版本：`pillow-1.0.0`。这是可完整游玩的网页 Demo，不是已经完成全部精制美术与配音的商业成品。

## 自动验证

- `npm test`：4 个测试文件、41 项通过。
- 八个结局均有明确见证路径，位于 `tests/paths.ts`；测试实际执行选择与状态判定，而非只检查结局节点存在。
- 校验原典事件顺序、隐藏结局的两段记忆链、今生与前世隔离、条件对白、重复选择保护与阶段行动预算。
- 使用 `fake-indexeddb` 验证存档读写、旧版保护、备份恢复以及失败时不覆盖记录。
- 300 次固定随机种子的人生压力测试均到达终幕，无卡死或负资源。
- 制作端测试覆盖来源完整性、受限候选结构、编译与知乎标识边界。
- `npm run build`：剧情导出、TypeScript 检查、Vite 与离线缓存构建通过。222 个预缓存条目，约 23.7 MiB。
- 依赖审计通过；本轮再次执行 `npm audit --omit=dev`，生产依赖报告 0 漏洞。

## 浏览器实际操作

使用应用内浏览器、真实按钮与页面状态测试，没有修改隐藏游戏状态来跳过流程。

1. 从开场进入三途分歧，完整游玩远行线至《四海有信》，82 岁、15 次落笔。
2. 第一季执行两次行动后，其余行动禁用；手动存档、继续推进、读档，恢复到原对白与已用完的行动预算。
3. 人生册只展示已读章节与已达终幕。可展开已读正文，未知内容不泄露隐藏条件。
4. 从《四海有信》重走“此去，何方”：恢复 20 岁、当时资源与关系，注入已获得的记忆，保留收藏和手动存档。
5. 关闭本项目的 4173 端口预览服务；TCP 连接明确失败后，重新加载已缓存页面，并恢复自动进度。
6. 服务保持关闭，完整游玩留乡线：拜师、工坊经营、汛期决策、工艺传承、晚年，抵达《一城灯火》，81 岁、14 次落笔。
7. 离线加载场景与终幕画作，声音开启和路线切换未出现游戏的音频加载失败提示。此项不等于专业音色试听验收。
8. “此生与彼生”实际对照这两次人生，分别显示故人去向、关键决定与承诺。
9. 检查 390 × 844 手机视口，修复导航图标无朗读名称、首页标题印章裁切、选择场景过长留白与说明文字过小的问题。
10. 在 320 × 740 最窄测试视口检查首页：文档没有横向溢出，标题、印章与按钮均处于可见范围。
11. 实际触发“去过一生”关键词动画，确认只点染目标短语、当前完整原句不变，再次点击才继续剧情；寿终回归后从 20 岁客栈开始新生。

最后的可玩预览改用独立端口 **4175**。原 4173 端口在上述离线整轮测试结束后被另一个本地项目使用，因此没有停止那个项目，也没有清除它所在地址的浏览器数据。端口属于浏览器存档与缓存隔离的一部分。

4175 完成全量缓存后再次停止本项目服务，前后两次 TCP 检查均失败；浏览器仍成功重载首页、启声并打开路线介绍，首页四个画作图片元素全部加载完成。随后恢复服务用于交付；该地址的人生册保留初始空白状态，不预先解锁测试结局。

离线验证针对已经完成缓存的同一浏览器与同一地址，不代表第一次访问、缓存被清理后或任何浏览器都能无条件离线启动。开发服务器不注册离线缓存。

## 演出与素材边界

- 88 个剧情节点、303 段对白，三条主线、隐藏合作线、八个结局。
- 使用 The Met 标为公有领域的古画，分层裁切、设色并生成八张终幕派生画面；来源及修改说明随包保存。
- 当前角色为有衣着差异、位置反馈和年龄变化的剪影立绘，不是精绘角色 CG。环境动态使用网页图层与矢量图形，不依赖完整 3D。
- 六首音乐均为原创五声主题、离线合成音色，长 85—133 秒；有分路线变奏、交叉淡化与关键关系场景静默。没有冒称真人古琴、琵琶或箫录音。
- 中文系统短句朗读默认关闭，依赖设备语音；尚未制作演员配音。
- 关键词强调需先读完原句，再点击触发，原文保留在回看中；减少动态效果与已读快进可跳过。没有高速闪烁或会移动点击位置的选项动效。
- 尚未完成陌生玩家阅读时长、长期文学质量、不同实体手机、屏幕阅读器和专业音频监听测试。

## AI 制作与外部内容

固定故事包可以完全断网运行。提供全文分析、候选生成、严格校验、人工审读确认与导出工具；模型密钥只在本地命令行制作端使用。

本次未配置 API 密钥，也未实际调用付费远程模型。模型生成路径已实现并做结构与编译测试，但真实接口、所选模型的输出质量与费用需要配置后另行验收；不将规则分析冒充模型结果。候选制作受本游戏角色与资产词表约束，不是任意小说的全自动转换器。

知乎比赛故事列表实际返回 HTTP 200、20 项；没有据此声称所有故事详情完整或获得任意改编授权。导入器保留来源，对摘要、截断和未审读内容设发布检查。
