# 入梦书封面与 ICON 提示词

以下直接用于你选择的图片生成工具。产品主体是“让许多知乎故事成为可亲历的世界”，不要让单个小妖怪角色占据品牌中心。

## 项目封面

**尺寸：16:9，1920×1080，PNG 或 JPEG，最终文件小于 5 MB。**

~~~text
为中文互动故事产品「入梦书」制作一张正式项目封面，16:9 横版，1920×1080。

视觉气质：温暖、安静、带文学感的东方幻想，精致绘本与电影场景融合。奶油白纸张、浅金光线、青绿色远山与深蓝梦境，细腻纸纹，清晰层次，不要廉价霓虹，不要科幻控制面板。

构图：左侧约 45% 留给醒目的中文排版，右侧约 55% 是视觉主体。一本展开的精装书悬在云上书屋中，翻起的书页变成一道发光的梦门；门内有三段不同故事世界自然交融：雨夜古镇的灯、幽深山林的小路、现代城市窗边的暖光。一个小小的读者背影站在书页形成的路上，面前分出两条若隐若现的光路，暗示选择与不同人生。人物只做尺度参照，书和梦境才是主角。前景纸页与少量星光向远处延伸，有进入故事的空间感。

必须出现且只出现以下三组简体中文，逐字准确，文字是真正的设计主体，绝不能缩成角落里的小字：
第一组，最大主标题：「入梦书」
第二组，醒目副标题：「把读过的故事，活一遍」
第三组，较小功能说明：「知乎故事 · 沉浸阅读 · 选择回响」

主标题置于左上至左中，约占画面高度的 25%，使用笔画饱满、清楚好认的中文书写艺术字体。颜色为深墨绿或深墨蓝；副标题用清晰的现代中文黑体，和主标题形成层次。左侧文字背景保持浅色干净，确保在项目广场缩略图里依然读得出「入梦书」。必要时用淡奶油色自然雾面承托文字，不要用粗糙贴纸块。

整体四周保留约 8% 安全边距；不要把字压在杂乱的树枝、书页或人物上。不要加入假的按钮、浏览器边框、二维码、水印、网址，不要出现「官方出品」「一键生成任意小说」之类额外文案。不要把示例小妖怪做成唯一主体，不要使用伪造的知乎官方标识。

输出清晰完整的正式封面，画面可以梦幻，中文文字必须醒目、完整、准确。
~~~

## 封面文字修正提示

如果画面满意但中文不准确，可以单独编辑文字区：

~~~text
保持现有插画、色彩、构图不变，只重做左侧文字排版。准确写出三行简体中文：
入梦书
把读过的故事，活一遍
知乎故事 · 沉浸阅读 · 选择回响

「入梦书」必须最大、最醒目，笔画完整可读。副标题明显大于说明文字。删除原来所有错误字符和多余文字，文字不与插画重叠，整体像经过专业中文排版的产品海报。
~~~

## 项目 ICON

**尺寸：1:1，1024×1024，PNG，最终文件小于 5 MB。**

~~~text
为中文互动故事产品「入梦书」设计一个正式项目 ICON，正方形 1:1，1024×1024。

图标中心是一枚极简、精致的浅金色打开书本符号，书页上方形成一扇圆拱梦门，门中只保留一颗小星与一条通向远处的光路。符号线条厚实清楚，视觉集中，细节克制，在 48×48 像素仍能识别「书通向另一个世界」。背景为深墨绿，带非常轻的纸纹或细腻渐变；奶油白和温金色作为主体，整体与东方文学幻想产品一致。

加入一个醒目、准确的简体中文大字「梦」，自然整合在梦门中心，笔画饱满清楚，不写三个小字「入梦书」，不添加英文。外轮廓为方形画布，内部允许柔和圆角构图，四周保留 12% 安全边距，便于平台自动裁切。不要复杂人物、整幅山水、二维码、假立体按钮、浏览器边框、水印或知乎官方标识。
~~~

## 导出时检查

- 封面主标题缩到约 320 像素宽时仍能看清；所有中文逐字核对。
- ICON 缩到 48×48 时检查轮廓和“梦”字，不保留依赖放大才能看见的装饰。
- 使用 RGB/sRGB，避免上传 SVG、WebP 或动图；页面仅接受 PNG、JPEG、JPG。
- 生成工具未保证文件大小时，使用 1920×1080 的 JPEG 高质量导出，或压缩 PNG 后再上传。
