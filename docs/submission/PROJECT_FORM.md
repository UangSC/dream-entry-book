### 入梦书

**把读过的故事，活一遍。**

读知乎故事时，我们常会想：如果我在场，会不会做出另一个选择？入梦书把这份念头变成可以亲身走过的一段旅程。

从知乎发现故事，挑选官方提供或获得授权的内容，借助 Agent 梳理人物、冲突与值得选择的时刻，再将故事装订为可游玩的“入梦书”。进入梦境后，文字、场景、角色表情和音乐共同推进叙事。你留下的每次选择，都可能在后来得到回应。

**你可以在这里做什么**

- 从知乎官方故事目录挑选下一篇想读的内容，也可以搜索原作、作者与相关讨论。
- 使用知乎直答生成入梦线索报告，在任务列表查看人物动机、核心冲突及分歧建议。
- 导入或导出包含剧情、立绘、背景和音乐的入梦书，收藏在自己的书架。
- 在沉浸式阅读中作出选择，使用自动播放慢慢读，用分歧回望重新走一段路。
- 收集故事的不同回响，再回到知乎阅读原作、发现作者和交流选择。

**我们希望带来的变化**

对读者，入梦书让对人物的理解变成一次有代入感的行动；对创作者，它提供一种可以保留署名、来源和作品气质的互动表达方式；对知乎，它为盐选与社区故事增加体验入口，让读者带着更具体的问题回到原作和讨论中。

当前提供可玩的示例故事、真实官方故事目录与知乎搜索、真实知乎直答线索分析，以及书架、存档、任务记录等能力。任意小说自动生成完整游戏仍在迭代，当前“制作流程演示”会清楚标注模拟产物。示例故事用于展示载体能力，未来每一本故事都可以成为新的入梦书。
