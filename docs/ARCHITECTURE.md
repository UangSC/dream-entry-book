## 首版技术选择

| 层 | 选择 | 目的 |
|---|---|---|
| 页面 | React + TypeScript + Vite | 静态部署、桌面与手机共用 |
| 数据契约 | Zod + 纯函数验证器 | 制作端与浏览器共享规范，发布前验证全部路径 |
| 剧情运行 | 无 IO 的确定性状态机 | 推进、条件与结算可独立验证 |
| 本地保存 | 按书与版本隔离的 localStorage KV + IndexedDB | localStorage 保存进度/梦签/设置/模拟任务，IndexedDB 保存完整入梦书与封面；不保存 API 凭证 |
| 离线 | 原生 Service Worker + 构建哈希清单 | 缓存应用外壳与已准备好的故事资源 |
| 演出 | CSS + 独立调度器 | 四种基础文字表现、14 种效果库（入场 8 / 退场 4 / 持续微动 2）、可跳过转场 |
| 音频 | Web Audio（AudioContext 时间线）+ 解码 AudioBuffer | 用户操作后启动，BGM/SFX 分组音量，等功率淡化与循环重叠靠绝对时间排程，不用媒体元素事件 |
| 律动 | 单一 rAF 驱动器 + CSS 自定义属性 | 由离线节拍图驱动的页面心跳；装饰层只读一个归一化包络值，不各自计时 |
| 制作工具 | Node + TypeScript，通过 tsx 运行 | 内容获取、两步生成、校验、审读记录与导出 |

依赖版本在建项时选择相互兼容的稳定版本并锁定。首版无登录、无服务端运行依赖；制作工具需要联网与安全凭证。场景渲染用 DOM 即可，无需先引入游戏引擎。

## 数据流与发布

```mermaid
flowchart LR
  A[比赛节选与来源记录] --> B[析梦：人物与事实表]
  B --> C[织梦：完整分支图]
  C --> D[结构与状态验证]
  D --> E[人工审读当前构建]
  E --> F[发布梦包与资源清单]
  F --> G[选梦与阅读]
  G --> H[选择与回响]
  H --> I[梦醒与梦册]
```

AI 只能产出 draft。审读工具把决定绑定到当前内容哈希与 buildId；编辑任一剧情或演出字段后失效。发布器重新验证、检查素材存在与来源记录，再生成目录。玩家端只读取发布目录；目录数据与梦包不一致时停止载入并报真实错误。

## 引擎与演出职责

`engine` 接收已校验梦包、旧状态和行动，返回新状态及展示事件。核心行动包括推进一拍、选择、恢复检查点、结束阅读。只有明确的剧情行动可以改变剧情位置；动画结束、音频结束、资源加载回调不能替玩家作选择。律动与特写同样不得进入这条链路：拍点、循环重叠、特效结束都不能触发推进或结算，`pulse` 与 `effects` 只读展示状态、不回写剧情状态。

同一拍的推进和同一选择点都使用行动令牌去重；旧令牌不能作用到新状态。连续点击要区分“立即显示当前拍”和“下一拍”，同一次按键不能兼做两件事。选择前验证当前拍已结束并确实到达选择点。

`director` 以展示事件 ID 去重。组件重渲染、窗口恢复、存档载入不会重复结算或重播一次性音效。恢复时通过已走路径重建场景与 BGM 的逻辑状态，详见 [梦包规格](DREAM_PACKAGE_SPEC.md)。

## 存储与版本

进度与当次选择历史序列化在同一条 localStorage 记录中原子写入；事务成功后才显示“已保存”。写入失败仍可阅读，但显示“本次进度尚未保存”并提供重试或导出，不能默默退化为内存模式。

存档、梦包、资源清单绑定 buildId 或各自内容哈希。旧构建有活动存档时不主动删除依赖；新旧包并存，兼容处理由用户可见地选择。应用更新只在首页或玩家主动重载时生效，不能在选择过程中强制刷新。

本地进度不跨设备同步。设置页提供导出与删除入口，删除当前进度与清空梦册分开。导入存档仅接受匹配已发布包的有界 JSON，重新检查状态与路径；存档导入与入梦书素材包导入为两个入口，后者验证完整 ZIP、媒体哈希和剧情图后才允许游玩。

## 离线与资源加载

首次访问且完全离线时没有网络应用外壳，不能承诺打开网页。首次在线载入后缓存外壳、首篇包、背景、角色静帧与声音；全部验证成功才标“离线就绪”。音频未齐时可标“可离线阅读，声音未齐”。

离线包按 buildId 暂存并核对必需文件后提交清单，避免下载中断留下半包。空间不足可重试或删除无存档依赖的旧包；不自动删除进度。浏览器仍可能清理缓存，启动时重新核对可用性。

先显示字体回退和角色静帧；只预载当前及下一节点背景，其他动画按需加载。背景失败用浅色底，音频失败静音（律动改走自由时钟，不消失），节拍图缺失或校验失败退回固定 72 BPM 自由呼吸，字体失败用系统字体；梦包 JSON 无效则不可推进，返回选梦页。

## 后续在线生成与验证

需要新增受控服务端：自身凭证、访问控制、配额预算、任务去重、超时状态与审读入口。OAuth 不能自动授予直答额度。在线任务完成只代表草稿生成，人工审读通过后才能公开游玩。

新增动画或特写必须同步 schema、映射、配额校验和词表；新故事只有在来源、结构和素材兼容时才能只加数据。验证重点是条件与结算、双击幂等、分支回滚、终幕可达、存档版本、资源失败和离线恢复。演出与可读性另做真实浏览器验证。
