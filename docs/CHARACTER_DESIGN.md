## 刘看山：温柔、好奇、偶尔困倦

“守梦人”是本项目的叙事安排，不声明为知乎官方角色设定。他看护梦斋，陪读者选书、送读者醒来；不声称知道未提供的原作结局，不评判选项，不推销会员。

语言短、自然，偶尔用书页与灯光的比喻。角色台词可以温柔，旁边系统状态必须准确；网络失败时不能只说“狐狸打个盹”而不给原因和操作。

| 时机 | 参考台词 | 系统配套 |
|---|---|---|
| 初见 | 「欢迎。今天想借哪一场梦？」 | 清楚展示“入梦”按钮 |
| 已准备好 | 「这一页，留给你来选。」 | 直接进入已审读故事，无假生成 |
| 制作等待 | 「我替你守着灯。」 | 仅真实任务时显示分析/编织/待审读状态 |
| 节选尽头 | 「这一页到这里了。真正的后续，还在原书里。」 | 结束本次梦；原文按钮独立显示 |
| 梦醒 | 「醒了？这一页，我替你收好了。」 | 梦签已保存；失败则改为未保存状态，不能照说 |
| 返回重玩 | 「枕头还在。要从哪一页重新开始？」 | 仅展示玩家到过的分歧点 |

## 动作使用

| ID | 动作 | 使用约束 |
|---|---|---|
| `MASCOT_IDLE` | 待机 | 首页与梦醒默认 |
| `MASCOT_WAVE` | 打招呼 | 首页随机动作；原设计 ID 为 `MASCOT_GREET` |
| `MASCOT_SWAY` | 晃悠 | 首页随机动作，不遮挡或追随指针 |
| `MASCOT_COMPUTER` | 电脑 | 首页休闲动作，不代表正在调用模型或处理真实任务 |
| `MASCOT_DOZE` | 瞌睡 | 首页随机打盹，梦内不出现 |
| `MASCOT_DRIBBLE` | 运球 | 首页随机动作，梦内不出现 |
| `MASCOT_STILL` | 待机静帧 | 首屏与减少动态效果的默认替代 |
| `MASCOT_LIBRARIAN` | 小馆员 | 美化副本保留，首页暂不显示 |

六段官方 GIF 已转为动画 WebP，保留原帧序和时长。压缩器会合并连续相同帧，因此验证按完整时间轴逐帧比较画面，而不是要求压缩后的帧数与 GIF 一样。

动作与短句使用两条独立的 5–30 秒随机时钟，不连续重复同一项。白色烟幕总长 3.6 秒，聚拢与散开各约 1.44 秒，中间短暂停留，在 1.8 秒、角色被遮住后换图。缓入缓出的缩放与透明度替代快速炸开的感觉；调度与 CSS 共用时长常量。首页隐藏、进入剧情或关闭动态效果时停止调度；页面回到前台重新安排计时，不补播后台积压的切换。减少动态效果时使用静帧和完整文字。

十二句台词由 AI 围绕入梦、选择、善意与小妖怪主题拟写，含标点不超过 20 字，采用自问、疑问和肯定句，例如“如果身在书中，我会怎样选择？”“故事还没结束，我也一样。”它们属于项目守梦人设定，不是名人引言或原作台词，不显示作者或作品署名。新短句从左到右以每字 65 毫秒逐字渐显。完整文字供读屏使用，自动换句不反复打断读屏。数据与调度分别见 [keeper.ts](../src/runtime/keeper.ts) 和 [HomeCompanions.tsx](../src/components/HomeCompanions.tsx)。

小馆员的原件保持在 `assets/source/art/reserve/poster-girl.svg`，美化副本为 [librarian.svg](../public/mascot/librarian.svg)，均保留但不在首页显示。刘看山与话语卡改为两列正常文档布局，移除看板娘占用的列与相关样式。

## 梦内角色卡

每个角色使用英文 ID，姓名与台词保留中文。角色卡字段以 [DREAM_PACKAGE_SPEC.md](DREAM_PACKAGE_SPEC.md) 为准。

- `role`：在原故事中的身份与关系。
- `desire`：当前想得到什么；`flaw`：为何容易做错或付出代价。
- `voice`：语气规则及 2 句拟写样例；区分“有来源的原句”和“审读用新写样例”，不能把拟写冒充原文。
- `sourceRefs`：支持人物设定的段落。未提供的性格背景保留未知，不用刻板印象补齐。

首篇目标 2–4 人。原文只有两个人也可成立，不为凑关系系统强添人物；原文人多时优先聚焦一个局部片段，不随意把几个有姓名的人合成一人后仍声称忠实改编。

叙述用第二人称，人物间对白沿用姓名。动作与心绪分配到 `narration` / `thought` 拍，不夹在 dialogue 的括号中。没有配音时“声音区分度”指书面语气，不承诺 TTS。

## 反漂移与表现

角色卡贯穿分析、编织与审读。每位主要人物检查至少 3 句、横跨冲突前后；角色可以成长，但变化须由已发生事件支持。只检查相同口头禅不足以证明一致，还要核对知识范围、动机与关系。

首版以姓名牌、说话标签、回顾面板中的人物说明识别角色，不靠颜色单独传达身份。后续若加人类立绘，先固定单个梦包的年龄、服装、轮廓和表情表，建立一致母版后再扩图；不对每次 AI 新梦临时生成一套。
