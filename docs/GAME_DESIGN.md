# 游戏设计总纲

## 定位与主题

**《入梦书》**，宣传语「读过的故事，值得一活。」保留书名，不将官方角色名作为项目品牌。

一句话定位：在刘看山守候的二次元梦境书屋里，把一段知乎故事读成自己选择的短篇人生。

二次元体现在清透背景、轻小说式对白卡、柔和光色与收藏设计；不强制恋爱、校园、抽卡，也不把所有原作改成古代或校园。目标用户是短篇故事读者、轻度视觉小说玩家；没有视觉小说经验也能直接开始。

## 首版核心体验

玩家在梦斋选一部已准备好的故事，阅读来源和题材提示后入梦。叙述使用第二人称“你”，对白沿用主角原名。每个选择表达可理解的行动与取舍，后果在故事中兑现，结尾保存为一枚梦签。

| 环节 | 对外名称 | 玩家行为 | 实现要求 |
|---|---|---|---|
| 发现 | 选梦 | 看封面、标签、作者、时长，选故事 | 只把可玩的已审读梦包显示为“入梦” |
| 内容制作 | 织梦 | 首版玩家无需等待 | 制作端生成、校验、审读；后续在线模式单独设计 |
| 游玩 | 入梦 | 读对白、作选择、查看回顾 | 首次实际点击后启动音频；随时保存退出 |
| 收束 | 梦醒 | 看局部结局、选择回响、梦签 | 不把试玩终点伪装成原作全文结局 |
| 重玩 | 记梦 | 从已到达的分歧点重选或换故事 | 结局收藏保留，分支状态回滚 |

## 首版范围与数值目标

- **1 个完整故事、2 个不同结局、3 个关键选择点**；每个选择点有 2 个行动选项。分支总图 8–12 节点，单条路线 6–8 节点。
- 单路线约 1,600–2,400 汉字，目标 6–10 分钟；首轮试玩后据阅读速度调整。不用节点数直接推断时长。
- 2–4 位有台词的主要人物；0–2 个故事资源、0–1 个关系指标，其余因果以事实标记表达。没有养成、刷资源或数值评分。
- 4 张核心背景、3 首 BGM、4 个音效、4 种文字表现；允许无声音完整通关。
- 第一优先题材为现代日常中的轻奇幻或轻悬疑：场景集中、冲突清楚、试读内可形成局部收束。具体篇目依据实际正文及使用依据筛选，不凭题名预定。
- 无账号、无 Key 输入、无付费点；桌面与手机浏览器均可玩。离线能力从首次成功访问并缓存后开始。

第二个故事在首篇验收后再做；人类角色立绘、CG、14 种演出、搜索热榜、OAuth、现场生成均是后续扩展。

## 选择为何有趣

每个关键选择必须回答：得到什么、放弃什么、何时回响。允许合流，但合流后必须保留不同的台词、关系事实或终幕回顾。禁止只有文字不同、所有后果相同的假分支。

选项不标“好感 +1”“正确路线”，也不预告结局；必须明确行动对象与可预见的代价。例如“留下陪她核对信件”与“赶在末班车前去车站”，比“勇敢 / 谨慎”更可理解。允许告知已知事实，不把必要信息藏起来制造误选。

梦醒至少展示：局部结果、1–2 条已发生选择的回响、相关人物此刻的去向、来源入口。梦册不提前剧透未解锁结局名称，收藏数量不作为付费或重玩门槛。

## 与知乎的关系

内容与生成能力来自知乎，游戏是独立网页，原文阅读返回知乎。比赛接口内容按“活动提供的有限节选”处理；保留作者与来源，确认适用使用范围。AI 变体围绕节选内尚未越界的分歧展开，不编造原作未知后续或揭秘未提供的真相。

“醒来”先进入游戏结局页；“去知乎读原文”是独立、明确的外链按钮。链接、价格与会员权益不编造。无法核实原文直链时说明“原文直链待补充”，给可选的知乎搜索入口，不制造伪链接。

## 设计边界

1. 所有公开梦包必须通过结构验证与人工审读。生成原稿保存在制作端，不自动对玩家开放。
2. “不出戏”约束剧情台词，不阻止清楚的按钮、存档提示、错误信息、来源标注与无障碍说明。
3. 官方刘看山保持原色原貌；正常梦内对白时退场，只在选梦、过渡、梦醒等边界出现。
4. UI 不强迫等待，不用假进度、不自动选项、不靠限时选择制造压力。
5. 动画、声音、字体下载或联网失败均不能阻断核心阅读。

## 首版验收

以下是待实施的目标，不是已测成绩：5 位未参与设计的试玩者中至少 4 位能独立开始并通关；至少 4 位能指出一个选择如何影响结果；两条结局可用实际选择路径到达；360px 手机宽度无正文或选项遮挡；刷新后正确续读；缓存后断网可完成首篇。

首屏可操作目标为普通移动网络下 3 秒内，预织梦包点击后 2 秒内显示可读首拍（设备与网络条件须在测试时记录）。生成时长不纳入首版玩家承诺；原文点击仅能衡量意愿，不能当作已带来会员转化。
